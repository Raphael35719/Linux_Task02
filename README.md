# Linux Task 02 — Linux Command Line Practical

A GitHub-ready workflow based on the supplied PDF. The practical is performed in Kali Linux as the newly created user `student01`; Git Bash on Windows is used to publish the project to GitHub.

## Start here
1. Read `what-to-do/TASK_GUIDE.md` and follow the steps in Kali Linux.
2. Track progress in `workflow/PROGRESS.md`.
3. Keep the original task PDF in `evidence/Raphael_Linux_Task_02.pdf` and add your own real screenshots to `evidence/`.
4. Compare with `outputs/EXPECTED_OUTPUTS.md`; save real command output in `outputs/actual/`.
5. Review `submission-notes/FINAL_REVIEW.md`, then publish using `workflow/GIT_BASH_GUIDE.md`.

## Directories
- `what-to-do/` — task explanation and ordered commands.
- `evidence/` — supplied PDF and screenshots from your own run.
- `workflow/` — progress tracker and Git Bash publishing instructions.
- `outputs/` — illustrative expected results and actual captured outputs.
- `submission-notes/` — final quality and submission checklist.

Expected output is reference material, not proof of completion. Do not commit passwords, tokens, private keys, or unrelated personal information.
